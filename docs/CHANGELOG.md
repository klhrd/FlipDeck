# Changelog

All notable changes to this project will be documented in this file.

## [5.4.0] - 2026-04-11
### Added（Roadmap 兩件套：雙面顯示 + 連結分享）
- **雙面顯示模式**：學習選單新增「顯示模式」切換（翻面 ⇄ 雙面），per-deck 持久化。雙面版面同時顯示正面/背面（上下分割），點擊與空白鍵不再翻面；滑動判定、跳過、復原、鍵盤全部照常。**SM-2 對映定案**：雙面模式答案可見，答對一律記 q=4（「看過答案後想起」），EF 不加成——進度語意誠實。手勢提示列在雙面模式自動隱藏「點擊 翻面」膠囊。
- **連結分享牌組（URL 內嵌、無後端）**：牌組設定（⋮）新增「複製分享連結」——精簡 JSON → `CompressionStream('deflate-raw')` → base64url 編入 `#d=` hash；**只傳靜態資料**（牌組 id、標題、card_id/fields/tags/notes），mastery/SM-2 進度不傳、由接收端自行累積。接收流程：開啟連結自動偵測 → in-app 確認（新匯入/覆蓋同 id 且**進度保留**）→ 匯入後清除 hash 防重複。壓縮後 >32KB 的大牌組（如 hs_6000）提示改用全域備份。
- **測試**：新增 `share.test.js`（round-trip/壓縮率/損毀防護）；`learning.test.js` 補雙面 q=4 斷言；`extractFn` 支援 `async function` 抽取。測試過程抓出生產碼兩個真 bug：`b64` 自我引用 TDZ、async 關鍵字被抽取器截斷。

### Changed
- **版本號升級**：v5.3.0 -> v5.4.0；SW `CACHE_NAME` 同步 bump。

## [5.0.0] - 2026-04-11
### Added（新主題：SM-2 間隔重複排程）
- **SM-2 演算法核心**：每張卡片新增 `ef`（難易度因子，下限 1.3）、`reps`、`interval`、`due` 欄位。答對即答（未翻面）記 q=5、翻面後才想起記 q=4、忘記記 q=2——EF 依標準公式更新；間隔為 1 天 → 6 天 → I(n-1)×EF。
- **到期制排程**：學習牌組由「熟練度排序」改為「到期優先（最逾期在前）」——到期（含逾期與新卡）才會出現；答錯的卡立即重新到期，由既有防回鍋機制控制重現節奏。答對後自動把已排到未來的卡移出本輪佇列。
- **到期資訊可視化**：首頁牌組卡顯示「N 張到期」徽章；學習統計新增「今日到期 / 7 天內到期」；完成畫面顯示下次到期時間與排程數。
- **資料遷移**：舊進度以 mastery 推估 SM-2 欄位（mastery 5 ≈ 38 天後到期），既有學習成果直接轉為合理排程、不會一次全部到期。

### Changed
- **undo 深度還原**：復原快照從單一 mastery 擴增為完整狀態（mastery + ef/reps/interval/due）。
- **熟練度保留為視覺指標**：5 級圓點、進度 %、統計圖含義不變；「再讀一輪」同時重置 mastery 與 SM-2 排程。
- **版本號升級**：v4.5.0 -> v5.0.0（核心演算法變更）；SW `CACHE_NAME` 同步 bump。

### Developer
- 自動化測試收進 repo：`test/auto/` 七套零依賴 node 套件（SW 快取策略、session/進度、學習判定/undo、抽卡佇列、備份還原、批次標籤/跳轉、SM-2），抽取 `js/script.js` 真實函式原始碼驗證；`npm test` 一鍵執行。手動測試清單見 `test/MANUAL_TEST_CHECKLIST.md`。
