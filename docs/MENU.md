# FlipDeck 功能清單 (Menu Functions)

## 首頁選單 (Home Menu)
位於首頁左上角的 ☰ 按鈕。

### 頂部圖示功能
- **匯入 / 範例**: 開啟快速開始視窗，可上傳 .txt, .csv, .json 檔案（或備份檔還原）。
- **全螢幕**: 切換瀏覽器全螢幕模式。
- **深淺色切換**: 手動切換深/淺色主題並記住偏好。
- **語言切換**: 中文 / English 切換並記住偏好。
- **關閉**: 關閉選單面板。

### 選單列表項目
- **從空白建立**: 使用圖形化介面從頭建立新的單字集。
- **全域備份 (.json)**: 匯出所有單字集的內容與學習進度為單一 JSON 檔。
- **操作教學**: 顯示程式的操作說明與教學。

## 首頁單字集設定選單 (卡片右上角 ⋮)
- close
- 單字集名稱 (編輯框)
- 複製分享連結（URL 內嵌、無後端；接收端匯入時進度自行累積，同 id 覆蓋保留進度）
- JSON 原始碼編輯
- 刪除單字集
- 儲存設定

## 學習中選單 (Learning/Deck Menu)
進入特定單字集後，位於畫面左上角的 ☰ 按鈕。

### 頂部圖示功能
- **回到首頁**: 離開目前單字集，返回主畫面。
- **匯入 / 範例**: 開啟快速開始視窗（載入成功會直接切換到新單字集）。
- **下載此單字集 (.json)**: 下載目前單字集的卡片內容。
- **全螢幕**: 切換瀏覽器全螢幕模式。
- **深淺色切換**: 手動切換深/淺色主題並記住偏好。
- **語言切換**: 中文 / English 切換並記住偏好。
- **關閉**: 關閉選單面板。

### 選單列表項目
- **顯示與編輯**
    - **顯示全卡片**: 以列表形式一次查看單字集內的所有卡片，可搜尋、跳至指定卡片、暫停/恢復特定卡，並可切換 JSON 原始碼或圖形化編輯（編輯器的融合中樞）。難卡（多次忘記）會顯示 bug 徽章。
    - **學習統計**: 顯示總進度、今日/7 天到期張數、未來 30 天到期預測圖、難卡與暫停數、5 級熟練度分布。
    - **圖形化編輯 (推薦)**: 使用視覺化編輯器修改目前單字集的內容（分頁 + 搜尋 + 批次標籤：勾選卡片後可一次加入/移除標籤）。
    - **操作教學**: 重看手勢與復原說明。
- **單字標籤篩選**: 根據單字個別的標籤進行篩選顯示 (可收合展開)。
- **字型大小 (Per-Deck)**: 調整目前單字集的文字顯示大小（-/+）。
- **每日新卡 (Per-Deck)**: 每天最多引入的新卡數量（預設 20，0 = 無上限）。
- **顯示模式 (Per-Deck)**: 翻面（點擊翻卡）/ 雙面（正背同時可見、免翻面）。
- **朗讀語言 (Per-Deck)**: 卡面朗讀鈕的發音語言——自動（內容偵測）/ zh-TW / en-US / ja-JP / ko-KR 循環切換，切換時示範朗讀當前卡。
