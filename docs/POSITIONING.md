# FlipDeck 定位筆記（2026-11-03，v5.11.0 時點）

產品 vs 市面產品差異分析。用途：決定「做什麼、不做什麼」的策略依據；隨版本演進定期回顧。

## 產品快照（v5.11.0）

純前端 PWA、零依賴零後端、無帳號、完全離線、免費。核心能力：SM-2 排程、欄位角色系統（正/背多欄＋小字＋欄位→標籤＋隱藏）、詞性自動版面偵測、Markdown/JSON/TXT 貼上匯入＋AI Agent 提示詞、無後端分享連結（#d= payload + QR）、Anki TSV 匯出、自由練習模式、進度/角色重置、i18n（zh/en）。

## 差異化優勢（該押注的）

1. **AI 時代的內容流入工作流**：貼 Markdown → 詞性版面偵測 → 亂序救援接合 → 一鍵複製 AI Agent 提示詞 → 產 JSON 貼上即用。市面無人做順「讓 AI 幫你做牌組」這條鏈——Anki 停在檔案思維、Quizlet 要手動輸入。**這是產品身分。**
2. **無後端分享**：`#d=` 連結＋QR，掃碼即用、離線可開、無帳號。教室/朋友即時分享場景獨家。
3. **欄位角色系統**：Anki 級彈性、Quizlet 級易用的中間點——即時可視、可逆、不動資料。
4. **零信任成本**：免費、無帳號、無廣告、資料不出裝置、單檔可審計——訂閱疲勞年代的定位優勢。
5. **誠實語意的小細節**：重置=立即到期、自由練習唯讀、chips 不謊報。

## 策略決議

- **不追**：遊戲化模式（Quizlet）、內建詞庫（墨墨）、帳號/雲端系統（違背零摩擦身分）。
- **補缺口順序**：① 自動本地快照 → ② 牌組市集 → ③ FSRS → ④ 圖片卡 → ⑤ Capacitor。
- **定位句**：*Anki 的排程彈性、Quizlet 的上手速度、零帳號零訂閱，加上為 AI 時代設計的建卡工作流。*
- **不做正面競爭**：站位於三者夾縫的明確生態位。

## 建議的 AI 工作流強化候選（未立案，僅記載）

- 匯入端支援解析 ChatGPT/Claude 分享連結（fetch 不可行→引導複製全文貼上已足夠，維持現狀）
- 格式說明中加入「常見 AI 輸出問題」對照（程式碼區塊圍欄、多餘說明文字）的自動清洗
- 牌組市集收錄流程中內建 AI 提示詞範本，讓貢獻者一鍵產出符合規格的牌組
