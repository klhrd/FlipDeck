# UI 按鈕結構

 > @是指在該選單的置頂快速功能去區

## 首頁

- ☰ 選單鈕
  - @[新增]
    - 從空白建立 → 圖形化編輯器
    - 上傳檔案 → 檔案選擇器
    - 貼上內容 → 展開貼上區
      - 格式說明（折疊）
        - 查看完整說明 → 格式說明視窗
    - 載入範例 [selector ▼] [▶]
  - @[設定]
    - 全螢幕
    - 深淺切換
    - 語言切換
  - 全域備份
  - 操作教學
- 空狀態按鈕「新增單字集」→ 新增選項視窗
- 牌組卡（點擊 → 學習畫面）
  - ⋮ 牌組選項 不要一點就直接讓焦點跑到輸入框使得開啟鍵盤
    - 名稱輸入框
    - 複製分享連結
      - QR Code
      - 連結文字框
      - 複製連結
    - JSON 原始碼 → JSON 編輯器
    - 刪除單字集
    - 儲存設定

## 學習畫面

- ☰ 選單鈕
  - @[回首頁]
  - @[下載] → 下載 .json
  - @[設定]
    - 全螢幕
    - 深淺切換
    - 語言切換
    - 字型大小 [-] 值 [+]
    - 每日新卡 [-] 值 [+]
    - 朗讀語言 [自動/zh-TW/en-GB/en-US/]
  - @顯示模式 [翻面/雙面]
  - 標籤篩選
  - 顯示全卡片
    - 搜尋框
    - 圖形化編輯器
      - 新增卡片
      - 分頁 [‹] X/Y [›]
      - 全選本頁 / 批次標籤 [加入][移除][✕]
      - 取消 / 儲存全部變更
    - [JSON 原始碼]
    - 每列：[跳至][暫停] 熟練度圓點
  - 學習統計
    - 進度 % + 已熟練 N/M
    - 今日到期 / 7 天內到期
    - 5 級分布圖
    - 30 天預測圖
  - 操作教學
- 卡面
  - 點擊 → 翻面
  - 左滑 → 忘記
  - 右滑 → 學會
  - 上滑 → 跳過
  - 🔊 朗讀鈕
- [復原] 膠囊（答題後 3.5 秒）
- 完成畫面
  - [再讀一輪]
  - [返回首頁]
