# FlipDeck 手動測試清單 (Manual Test Checklist)

**版本**: v5.1.0　**範圍**: v4.1.4 → v5.1.0 全部變更
**建議環境**: 桌機 Chrome/Edge + 手機 Chrome（安裝成 PWA 各測一次）

---

## 0. 事前準備

- 本清單多數功能需透過 `http://` 或 `https://` 開啟（Service Worker 不支援 `file://`）。
- **DevTools 位置**：
  - 應用程式 → Service Workers：查看 SW 註冊狀態
  - 應用程式 → 本機儲存空間：查看資料（金鑰見下）
  - 主控台：可貼本清單提供的輔助程式碼
- **localStorage 金鑰**：
  | 金鑰 | 內容 |
  |---|---|
  | `flashcardPWA_deckList_v2` | 牌組清單（標題、進度） |
  | `flashcardPWA_data_v2_<id>` | 牌組卡片資料 |
  | `flashcardPWA_state_v2_<id>` | 每卡狀態（mastery / ef / reps / interval / due） |
  | `flipdeck_uxFlags_v1` | 首啟引導旗標 |
  | `flipdeck_theme` | 主題偏好 |
  | `flipdeck-cache-v5.0.0` | SW 快取（於 Cache Storage） |
- **輔助：一鍵把牌組全部改成立即到期**（模擬逾期/到期日，測 SM-2 必備，貼到主控台後重新整理）：
  ```js
  const id = 'd_1712800000000';            // 換成實際牌組 id（deckList 內可查）
  const k = 'flashcardPWA_state_v2_' + id;
  const s = JSON.parse(localStorage.getItem(k));
  Object.values(s).forEach(v => v.due = 0);
  localStorage.setItem(k, JSON.stringify(s));
  location.reload();
  ```
- **輔助：觀察單卡 SM-2 欄位**：
  ```js
  const s = JSON.parse(localStorage.getItem('flashcardPWA_state_v2_d_1712800000000'));
  console.table(s);   // 看 mastery / ef / reps / interval / due
  ```
